# Auto Venda Mais

## Descrição

Auto Venda Mais é uma plataforma web e mobile para compra e venda de carros, motos e autopropelidos (bicicletas e patinetes elétricos) com foco na procedência garantida e confiança nas transações.

## Estrutura do Projeto

- `backend/`: Contém o backend da aplicação construído com Node.js e Express.
- `frontend/`: Contém o frontend da aplicação construído com React e React Native.
- `docs/`: Documentação do projeto.

## Como Executar

### Backend

1. Navegue para o diretório `backend`:
   ```sh
   cd backend
   ```
2. Instale as dependências:
   ```sh
   npm install
   ```
3. Inicie o servidor:
   ```sh
   node server.js
   ```
4. Acesse a API em `http://localhost:3000`.

### Frontend

1. Navegue para o diretório `frontend`:
   ```sh
   cd frontend
   ```
2. Instale as dependências:
   ```sh
   npm install
   ```
3. Inicie a aplicação web:
   ```sh
   npm start
   ```
4. Acesse a aplicação em `http://localhost:3000` (ou a porta configurada).
